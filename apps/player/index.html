Network & WebXR notes

Open this page from the Quest Browser using the same LAN address shown in the dashboard. Flat 2D and drag-to-look 180/360 playback work over HTTP. Immersive WebXR playback requires HTTPS (a local certificate trusted by the headset) or localhost.

If the headset shows a certificate warning, choose Advanced → Proceed once, or download the local CA certificate and install it under Settings → Security → Install CA certificate. Trusting the certificate removes the warning permanently.
